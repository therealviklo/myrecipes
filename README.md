# MyRecipes
Det här är ett grupprojekt som gjordes av Alexandra Perméus, Viggo Strömberg och Alice Ångström för kursen "Informationssystem B: E-tjänster och webbprogrammering" på Uppsala Universitet. Det är en webbsida som är en slags sociala medier-plattform där användare kan dela med sig av recept. Projektet är gjort i PHP. Den använder sig också av två externa API:er: en för att ta reda på vad för allergener som finns i receptet och en för att importera existerande recept.

En statisk demoversion finns på https://myrecipes.viklo.se. Man kan inte publicera inlägg eller skapa konton men man kan få en känsla för hur den här webbplattformen skulle fungera om man drev den på riktigt.
